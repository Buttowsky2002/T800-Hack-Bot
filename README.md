# T800-Hack-Bot
The T-800 Hack Bot is an AI-driven offensive security tool designed to automate and enhance the full penetration testing lifecycle. Leveraging the power of the ChatGPT API, the system functions as an intelligent assistant that dynamically guides, executes, and optimizes each stage of a pentest engagement.


## Setup
1. `pip install -r requirements.txt`
2. Copy `config.yaml.example` to `pentest_bot_t800/config/config.yaml` and fill in your values
3. Set `ANTHROPIC_API_KEY` environment variable
4. `python -m pentest_bot_t800 interactive`
